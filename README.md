# AIKosh AI/ML Readiness Check for Structured Dataset

This package keeps the existing structured-data assessment engine unchanged and adds a professional web interface around it.

## Run locally

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

The application opens at `http://127.0.0.1:8000`.

## UI features

- AIKosh AI/ML Readiness Check for Structured Dataset branding
- Existing structured-data quality, privacy and AI/ML readiness logic retained
- Clear Fit / Conditional / Not fit status using checkbox-style visual indicators
- Assessment score line with the existing 0 to 60 scale and 36 / 42 decision thresholds
- Missing, Columns, PII and Small groups evidence tabs
- Data visualization tab containing all charts generated by the existing engine: batch fitness distribution, score breakdown and missing-value charts
- Metadata report pre-populated from assessment results where information is available, with fields for the user to complete when required information is missing
- Master report, metadata report, individual Excel report and complete ZIP downloads

## Command-line engine

The analytical engine remains available directly:

```powershell
python data_quality_toolkit.py -i <file_or_folder> -o <out_folder>
```

Environment variables: `DQ_PORT`, `DQ_HOST`, `DQ_MAX_UPLOAD_MB` (default 500).
